# ECommerce-Sales-And-Marketing-Audit-360

An integrated multi-channel data audit analyzing and auditing performance across Facebook Ads, Google Ads, and Shopify Sales platforms using advanced Excel and Power BI dashboards.

---

## 📌 Executive Summary
This project provides a comprehensive 360-degree performance audit of multi-channel e-commerce operations. By consolidating data from advertising platforms and sales funnels, this audit evaluates campaign effectiveness, customer acquisition costs, return patterns, and overall revenue contribution.

---

## 🛠️ Tech Stack & Tools
* **Microsoft Excel:** Data cleaning, preprocessing, and multi-source data integration.
* **Power BI (DAX):** Interactive cross-filtering executive dashboards, custom measures, and KPI tracking.

---

## 📁 Repository Files & Structure
* `Facebook_Ads_data.xlsx`: Campaign performance, reach, impressions, and ad spend metrics.
* `Google_Ads_data.xlsx`: Search/Display campaign analytics and click-through metrics.
* `Shopify_sales_data.xlsx`: Transaction records, order volumes, revenue, and product return data.
* `Project facebook.pbix`: Power BI interactive dashboard for Facebook marketing attribution.
* `GOOGLE PROJECT.pbix`: Power BI dashboard visualizing Google Ads performance.
* `Shopify project.pbix`: Power BI sales and revenue breakdown dashboard.

---

## 📊 Key Insights & Highlights
* **Multi-Channel Integration:** Evaluated cross-platform marketing impact against actual product sales.
* **Interactive Visualizations:** Built isolated and comparative dashboards for granular platform auditing.
* **Business Optimization:** Identified high-performing channels to guide data-driven budget allocation and risk mitigation.
